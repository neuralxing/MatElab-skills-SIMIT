# 模板设计规格：晶体生长与表征记录

> **当前实际使用的是实验室已有模板 `Flux method simit`**，字段映射见
> `template-flux-method-simit.md`。本文档保留为「自建模板」方案：当需要中文模块名、
> 独立 EDS 成分表、电学/磁性模块时按本文建一套。

在 MatElab 网页端一次性建好，之后所有记录复用。**模块名与字段名必须一字不差**地写进 `matelab.yaml` 的 `field_map`（中英文括号、全角半角都算）。

## 一、模板总览

| # | 模块名 | 类型 | 用途 |
|---|---|---|---|
| 1 | 基本信息 | 表单 | 样品身份、实验类型、日期 |
| 2 | 合成工艺 | 表单 | 助熔剂法 / CVT / 固相烧结的工艺参数 |
| 3 | 原料配比 | 表格 | 原料、纯度、摩尔比、质量 |
| 4 | EDS成分 | 表格 | 元素、线系、Wt%、Atomic% |
| 5 | XRD与物相 | 表单 | 物相、空间群、晶格参数、结论 |
| 6 | 电学输运 | 表单 | 电阻率、载流子、迁移率 |
| 7 | 磁性 | 表单 | M-T / M-H、转变温度 |
| 8 | 实验过程与现象 | 图文混排 | 摘要、过程、现象、结论（富文本） |
| 9 | 原始数据与图片 | 文件集 | XRD/EDS/PPMS 原始文件与照片 |

## 二、字段明细

### 1. 基本信息（表单）

| 字段名 | 数据格式 | 必填 | 说明 |
|---|---|---|---|
| 样品编号 | 单行文本 | ✓ | 如 `XY101`，与 uid 前缀一致 |
| 化学式 | 单行文本 | | 如 `BiSiTe3`，可用化学式编辑器 |
| 实验类型 | 级联选择 | ✓ | `助熔剂法单晶生长` / `CVT气相输运` / `固相烧结` / `其他` |
| 生长日期 | 日期 | ✓ | 格式 `2026-09-24` |
| 操作人 | 单行文本 | | |
| 项目课题 | 单行文本 | | 便于按项目检索 |
| 目标产物 | 单行文本 | | |
| 记录UID | 单行文本 | ✓ | 幂等键，脚本自动填 `XY101-20260924-01` |

### 2. 合成工艺（表单）

| 字段名 | 数据格式 | 必填 | 说明 |
|---|---|---|---|
| 生长方法 | 级联选择 | ✓ | `助熔剂法` / `CVT` / `固相烧结` / `其他` |
| 助熔剂/输运剂 | 单行文本 | | 如 `Te 自助熔剂`、`I2 5 mg/cm³` |
| 坩埚 | 单行文本 | | `Al2O3` / `石英` / `Mo` |
| 气氛 | 级联选择 | | `真空` / `Ar` / `N2` / `空气` / `封管真空` / `其他` |
| 封管真空度(Torr) | 单行文本 | | 允许 `1e-4`、`<10^-4` 等写法，故用文本 |
| 最高温度(℃) | 数字 | ✓ | 625 |
| 保温时间(h) | 数字 | ✓ | 14 |
| 降温速率(℃/h) | 数字 | | 5 |
| 源区温度(℃) | 数字 | | CVT 专用 |
| 生长区温度(℃) | 数字 | | CVT 专用 |
| 分离方式 | 级联选择 | | `离心` / `倾析` / `机械剥离` / `不分离` / `其他` |
| 产率(%) | 数字 | | 只填数字，不要带 `%` |

> 为什么只给这 5 个字段用「数字」：MatElab 表格/表单数字列传字符串会直接 `code:2` 整条失败。
> 会写成 `~`、`未测`、`1e-4`、`2-300 K` 的一律用文本。

### 3. 原料配比（表格）

| 列名 | 数据格式 |
|---|---|
| 原料 | 文本 |
| 纯度 | 文本 |
| 摩尔比 | 数字 |
| 质量(g) | 数字 |
| 备注 | 文本 |

### 4. EDS成分（表格）

| 列名 | 数据格式 |
|---|---|
| 元素 | 文本 |
| 线系 | 文本 |
| Wt% | 数字 |
| Atomic% | 数字 |
| 备注 | 文本 |

多元素时按行扩展；总数行不必录入（可由脚本写进结论）。

### 5. XRD与物相（表单）

| 字段名 | 数据格式 |
|---|---|
| 物相 | 单行文本 |
| 空间群 | 单行文本 |
| 晶格参数 | 单行文本（如 `a=4.12 Å, c=30.1 Å`） |
| XRD结论 | 多行文本 |

### 6. 电学输运（表单）

| 字段名 | 数据格式 |
|---|---|
| 测试项目 | 单行文本（电阻率 / 霍尔 / 热电势） |
| 温度范围 | 单行文本（`2-300 K`） |
| 电阻率(Ω·cm) | 单行文本（常需科学计数法或范围） |
| 载流子类型 | 级联选择：`n型` / `p型` / `双极` / `未测` / `其他` |
| 载流子浓度(cm^-3) | 单行文本 |
| 迁移率(cm^2/V·s) | 单行文本 |
| 结论 | 多行文本 |

### 7. 磁性（表单）

| 字段名 | 数据格式 |
|---|---|
| 测试项目 | 单行文本（M-T / M-H / 交流磁化率） |
| 温度范围 | 单行文本 |
| 磁化强度 | 单行文本（含单位，如 `0.8 μB/f.u.@2K, 1T`） |
| 磁转变温度(K) | 数字 |
| 结论 | 多行文本 |

### 8. 实验过程与现象（图文混排）

脚本写入 HTML 段落：摘要 → 配料与工艺 → 现象 → 表征结论。图片不放这里（放文件集更稳）。

### 9. 原始数据与图片（文件集）

建议建两个文件夹：
- `表征原始数据/`：XRD `.xy`/`.raw`、PPMS `.dat`、EDS `.docx`/`.pdf`
- `样品照片/`：`.jpg`/`.png`

文件集的说明文本（caption）由脚本从 `attachments[].text` 写入。

## 三、网页端建模板步骤

1. 登录 → **记录本** → 打开 `晶体生长记录` → **新建记录**，模板选「不使用模板」。
2. 依次「增加模块」，按上面 9 个模块建好，**模块名逐字照抄**。
3. 每个表单/表格按字段表添加字段，数据格式照抄；级联选择的选项也照抄。
4. 保存记录 → 右上角 `⋮` → **原数据 → 另存为模板** → 模板名填 `晶体生长与表征记录`。
5. 回到记录本新建一条记录，模板选 `晶体生长与表征记录`，确认 9 个模块都在。
6. 跑 `check_template.py --config matelab.yaml`，全绿即完成。
7. 建好的这条测试记录可以删掉（或留着当人工对照）。

### 命名约束

- 模块名、表单字段名、表格列名：**不可为空、不可重复**（重名会导致保存失败）。
- 级联选择的值必须与 `field_map` 的 `choices` 完全一致，否则导入被拒。
- 字段名里带单位请用中文括号 `(℃)` 或直接 `(℃)`——建完模板后把 `matelab.yaml` 里的 `field` 改成一模一样即可，不必改代码。

## 四、可选：两个模板方案

若觉得一个模板字段太杂（比如 CVT 的源区/生长区温度对助熔剂法恒为空），可拆成两个模板：

- `晶体生长与表征记录-助熔剂法`
- `晶体生长与表征记录-CVT`

代价是 `check_template.py` 与上传要按实验类型选模板，`config.yaml` 里用 `template_by_exp_type` 指定。默认不拆，先跑单模板。
